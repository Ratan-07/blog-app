# Internship Project — Blog Application

This repository contains the Blog Application project built during my internship, covering both frontend interface design and backend API integration.

---

## Module 1: Day 1 – Day 4 (Frontend Development)

* Set up the local development environment.
* Implemented core fundamentals using HTML, CSS, and JavaScript.
* Designed a responsive Blog Application interface.
* Created pages: Home, Login, Register, Dashboard, and Create Blog.

---

## Module 2: Day 5 – Day 8 (Backend Development)

* Set up a backend server using Node.js and Express.js.
* Created REST APIs for the application.
* Built APIs for User Registration, User Login, and Create Blog.
* Connected the frontend interface with the backend APIs.
